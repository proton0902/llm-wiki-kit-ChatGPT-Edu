# 자료 소화 (학습용)

## 0. 대상 찾기
- 지정하지 않으면 `raw/` 아래 파일 중 어떤 페이지의 `source:`에도 없는 파일을 찾아 과목·종류별로 보여 준다.
- 주차 순서대로 처리하자고 제안한다. 한 번에 한 파일씩 끝까지 처리한다.

## 1. 원문 읽기 (위치 보존)
- `.pptx`: `python3 scripts/pptx_slides.py 파일.pptx` → `=== s.N ===`이 슬라이드 번호, `[노트]`는 발표자 노트.
- `.pdf` (슬라이드를 PDF로 받은 경우 포함): `python3 scripts/pdf_pages.py 파일.pdf` → `=== p.N ===`. 슬라이드 PDF면 쪽 번호를 슬라이드 번호(s.N)로 쓴다.
- 그림·수식이 이미지라 글자가 거의 안 나오는 슬라이드는 `(그림 슬라이드, 내용 확인 필요)`로 남기고 사용자에게 알린다. 추측해서 채우지 않는다.
- 원문 파일은 수정하지 않는다.

## 2. 페이지 쓰기
- **강의 슬라이드** → `wiki/lectures/<과목>-wNN-<주제>.md`. 주차는 파일명·슬라이드 제목·강의계획서로 판단하고, 모르면 묻는다.
- **교재** → 장마다 `wiki/chapters/<교재약칭>-chNN-<주제>.md`. 한 번에 한 장씩.
- **필기** → 해당 강의 페이지에 "내 필기에서" 항목으로 합친다. 필기에만 있는 강조는 `⭐ 강조 (필기)`.
- **기출·연습문제** → `wiki/problems/`. 문제 원문 전체를 복사하지 않고 요약한다.
- **과제** → 문제 페이지를 만들지 말고, 쓰이는 개념만 개념 카드에 "관련 과제"로 링크한다 (`AGENTS.md` 3장).
- 모든 내용에 `s.N` 또는 `p.N` 출처. 교수님 강조는 `⭐ 강조`.

## 3. 개념 카드와 연결
- 강의·교재에 나온 핵심 개념마다 `wiki/concepts/` 카드를 찾고, 있으면 출처와 예제를 보태고, 없으면 만든다.
- 선수 개념·이어지는 개념을 링크해 개념 지도를 만든다.
- 슬라이드와 교재의 정의·표기가 다르면 수업 기준으로 쓰고 교재 표기를 함께 적는다. 과목 허브의 "표기법·기호" 표도 갱신한다.

## 4. 마무리
- 과목 허브의 "주차별 강의" 표에 강의 페이지를 링크한다.
- `wiki/index.md`를 갱신한다.
- `wiki/log.md`에 `- 날짜 | ingest | 페이지명 | 새 페이지 N개, 개념 카드 M개, 확인필요 K개` 추가.
- 사용자에게 보고: 이번 자료 한 줄 요약, 새 개념 카드, ⭐ 강조 목록, 확인 필요 항목. 그리고 "이해 확인 퀴즈를 내 볼까요?"라고 묻는다.
