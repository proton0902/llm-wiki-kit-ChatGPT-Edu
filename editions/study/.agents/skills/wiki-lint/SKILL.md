# 위키 건강검진 (학습용)

## 1. 기계적 점검
`python3 scripts/wiki_stats.py` 실행: 페이지·링크 수, 깨진 링크, 고아 페이지, 출처(s./p.) 없는 강의·교재 페이지, 원문 파일 없는 페이지, 미소화 raw 파일.

## 2. 내용 점검
- **빠진 주차**: 과목 허브의 주차 표와 강의 페이지 비교.
- **표기 불일치**: 같은 기호가 페이지마다 다른 의미로 쓰인 곳. 수업 표기로 통일.
- **중복 개념 카드**: 같은 개념 카드 두 개 → 합치기.
- **출처 없는 설명**, `(보충 설명)` 표시 없이 자료 밖 내용이 섞인 곳.
- **개념 지도 끊김**: 선수 개념 링크가 없는 카드.
- **학업 윤리**: 채점 과제의 완성 풀이가 위키에 들어간 곳 → 힌트로 바꾸자고 제안.
- **개인정보**: 다른 학생 이름·학번이 들어간 곳.

## 3. 고치기
- 먼저 표로 보여 준다: `| 종류 | 위치 | 내용 | 제안 |`. 동의를 받고 고친다. `raw/`는 수정하지 않는다.

## 4. 기록
`wiki/log.md`에 `- 날짜 | lint | 전체 | 발견 N건, 수정 M건` 과 1번 통계 한 줄.
