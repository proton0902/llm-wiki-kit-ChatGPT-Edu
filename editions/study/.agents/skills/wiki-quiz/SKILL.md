# 퀴즈·간격 반복 (학습용)

## 퀴즈 내기
1. 범위를 묻는다: 과목, 주차·장, 개념, 또는 "오늘 복습할 것". 문제 수(기본 5)와 유형(개념 확인 / 계산 / 서술 / 섞어서)도.
2. "오늘 복습할 것"이면 `wiki/review/quiz-log.md`에서 **다음 복습일이 오늘 이전인 개념**과 `mastery: learning` 개념을 우선 고른다.
3. 문제는 위키 내용에서만 낸다. 각 문제에 출처(s.N / p.N)를 기록해 두되, **채점 전에는 답과 출처를 보여 주지 않는다.**
4. ⭐ 강조된 내용과 기출 유형을 우선한다. 같은 퀴즈에서 같은 개념을 두 번 묻지 않는다.

## 채점
5. 사용자가 답하면 문제마다 맞음 / 부분 / 틀림, 이유, 올바른 답, 출처를 보여 준다.
6. 틀린 문제는 `wiki/review/<과목>-오답노트.md`에 추가한다: 문제 요약, 내 답, 왜 틀렸는지(개념 오해 / 계산 실수 / 기억 안 남), 올바른 생각, 관련 개념 카드 링크.
7. 개념 오해로 틀렸으면 해당 개념 카드의 "흔한 실수"에 추가할지 묻는다.

## 간격 반복 기록
8. `wiki/review/quiz-log.md` 표에 개념별로 기록한다: `| 날짜 | 개념 | 결과 | 연속 정답 | 다음 복습일 |`
   - 다음 복습일: 틀림 → 1일 뒤, 연속 정답 1회 → 3일, 2회 → 7일, 3회 이상 → 14일. 날짜 계산은 스크립트로.
9. 연속 정답 3회 이상이면 개념 카드의 `mastery`를 `mastered`로, 틀리면 `learning`으로 바꾼다.
10. `wiki/log.md`에 `- 날짜 | quiz | 범위 | N문제 중 M개 정답` 추가.
