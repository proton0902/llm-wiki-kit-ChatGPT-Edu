# 과목 등록 (학습용)

## 절차
1. `AGENTS.md` 8장을 읽는다. 이미 등록된 과목이 있으면 보여 주고 추가·수정할 과목을 묻는다.
2. 아래를 **한 번에** 묻는다.
   - 이번 학기와 듣는 과목 이름 (짧은 약칭도 함께. 예: 회로이론 → circuits)
   - 시험 일정을 알면 알려 주세요.
   - 설명 수준: 쉽게 / 보통 / 자세히
3. 과목마다 `raw/lectures/<약칭>/` 폴더를 만들고, `wiki/courses/<약칭>.md` 허브 페이지를 `AGENTS.md` 4장 양식으로 만든다.
4. `raw/lectures/<약칭>/`에 강의계획서(syllabus)가 있으면 읽어서 허브의 "한눈에 보기", "주차별 강의" 표, "시험 범위"를 채운다(출처 표시). 없으면 빈 표로 둔다.
5. `AGENTS.md` 8장(학기, 과목 목록, 시험 일정, 설명 수준)을 채운다. 다른 장은 건드리지 않는다.
6. `wiki/index.md`의 "과목"에 허브 링크를 추가한다.
7. 안내한다: "강의자료는 `raw/lectures/<약칭>/`, 교재는 `raw/textbooks/`에 넣고 `$wiki-ingest`를 입력하세요."
8. `wiki/log.md`에 `- 날짜 | setup | 과목 등록 | N과목` 추가.
