# 시험 대비 (학습용)

## 절차
1. 과목과 시험을 확인하고, 과목 허브의 "시험 범위"를 읽는다. 범위가 비어 있으면 사용자에게 묻는다(추측하지 않는다).
2. 범위 안의 강의·교재 페이지와 개념 카드를 모은다. ⭐ 강조, 기출(`wiki/problems/`), 오답노트, `quiz-log.md`의 약한 개념을 함께 본다.
3. `wiki/review/<과목>-<시험>-요약.md`를 만든다.
   - **범위 한눈에**: 주차·장 목록과 페이지 링크
   - **꼭 나올 것**: ⭐ 강조 + 기출 반복 개념 (출처 포함). 근거 없는 "나올 것 같다"는 쓰지 않는다.
   - **공식·정의 한 장**: 기호는 수업 표기
   - **내 약점**: 오답노트와 퀴즈 기록에서 `learning` 개념
   - **유형별 풀이 전략**: 기출 유형마다 접근 순서
   - **예상 문제 5~10개**: 위키 내용에서만. 답은 맨 아래 접어서
4. 시험일을 알면 오늘부터 시험 전날까지 **하루 단위 공부 계획**을 제안한다(약점 우선, 마지막 날은 전체 복습과 퀴즈).
5. `wiki/log.md`에 `- 날짜 | exam | 과목-시험 | 범위 N주차, 약점 개념 M개` 추가.
