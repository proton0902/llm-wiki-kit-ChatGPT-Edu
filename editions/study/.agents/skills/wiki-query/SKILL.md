# 질문·설명 (학습용)

## 절차
1. **`wiki/index.md`에서 출발**해 과목 허브 → 관련 개념 카드·강의 페이지를 읽는다.
2. 설명 수준은 `AGENTS.md` 8장 기본값을 따르고, 사용자가 "쉽게", "자세히", "시험용"이라고 하면 바꾼다.
3. 답변 구성 (개념 질문의 기본):
   - 첫 문장에 핵심 답.
   - 정의 → 직관 → 수식 → 예제 → 흔한 실수 (필요한 것만).
   - 모든 내용에 출처 `([[lectures/...]], s.N)` / `([[chapters/...]], p.N)`. 자료 밖 내용은 `(보충 설명)`.
   - 수업과 교재 표기가 다르면 수업 기준으로 쓰고 차이를 알린다.
4. **문제 풀이 질문**이면 `AGENTS.md` 3장(학업 윤리)을 먼저 확인한다.
   - `raw/assignments/`에 있는 채점 과제면: 개념 설명, 비슷한 예제, 단계별 힌트만. 사용자가 자기 풀이를 보여 주면 어디가 맞고 틀렸는지 피드백.
   - 연습문제·기출·제출 끝난 과제면: 풀이 전략 → 단계별 풀이 → 검산.
5. **"내가 설명해 볼게"** 모드: 정답을 먼저 말하지 않는다. 사용자의 설명을 듣고 맞은 점, 빠진 점, 틀린 점을 출처와 함께 짚는다. 틀린 점은 해당 개념 카드의 "흔한 실수"에 추가할지 묻는다.
6. 위키에 근거가 없으면 "이 과목 자료에서 근거를 찾지 못했습니다"라고 말하고, 보충 설명이 필요한지 묻는다.
7. 다시 볼 만한 답이면 `wiki/answers/`에 저장할지 묻는다.
8. 마지막 줄에 "읽은 페이지: …". `wiki/log.md`에 `- 날짜 | query | 질문 요약 | 읽은 페이지 N개` 추가.
