# 정확도 검증 키트

"LLM Wiki가 정말 더 정확한가?"를 숫자로 보여 주기 위한 도구입니다.

## 1. 정답 세트 만들기 (사람이 직접)
`questions.csv`에 질문 30~40개를 씁니다. **정답과 출처(논문, 쪽)는 반드시 원문을 보고 직접** 적습니다.

| type | 의미 | 권장 개수 |
| --- | --- | --- |
| `single` | 한 논문의 수치·사실 | 10~15 |
| `cross` | 여러 논문 비교·검색 | 10~15 |
| `trend` | 동향·종합 | 5~10 |
| `unanswerable` | 위키에 답이 없는 질문 (지어내는지 확인) | 3~5 |

## 2. 세 가지 조건으로 답 받기
같은 질문을 아래 조건에서 각각 **2회씩** 묻고 `results.csv`에 기록합니다.

| condition | 방법 |
| --- | --- |
| `A_chat` | ChatGPT Edu 일반 채팅에 PDF를 첨부하고 질문 (한 번에 첨부 가능한 만큼) |
| `B_project` | ChatGPT Edu 프로젝트(또는 GPT)에 PDF를 지식 파일로 올리고 질문 |
| `C_wiki` | 이 위키 폴더에서 Codex에게 `$wiki-eval` 실행 |

A, B는 사람이 복사해 붙여 넣고, C는 `$wiki-eval`이 자동으로 기록합니다.

## 3. 채점과 요약
- `correct`: yes / partial / no, `source_ok`: yes / no, `fabricated`: yes / no
- 사람이 확인한 행은 `grader`를 `human`으로 바꿉니다.
- `python3 eval/score.py` 를 실행하면 조건별 요약 표가 나옵니다.

## 공정하게 하려면
- 질문은 위키를 만들기 전에, 또는 위키를 보지 않고 원문만 보고 만듭니다.
- 세 조건 모두 같은 질문 문장을 그대로 씁니다.
- 결과가 나쁘게 나온 조건도 그대로 보고합니다. 틀린 원인을 분석해 `AGENTS.md`를 고치고 다시 재는 과정 자체가 좋은 결과입니다.
