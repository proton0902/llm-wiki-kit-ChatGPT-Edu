# 위키 맞춤 설정 (연구자용)

목표: 5분 안에 이 위키를 사용자의 연구에 맞춘다.

## 절차
1. `AGENTS.md`를 읽는다. 9장이 이미 채워져 있으면 현재 값을 보여 주고 무엇을 바꿀지 묻는다.
2. 아래 질문을 **한 번에** 묻는다. 모르면 비워도 된다고 안내한다.
   - 연구 분야와 지금 하는 연구를 두세 문장으로 설명해 주세요. (미발표 내용은 이 PC 안에만 저장됩니다.)
   - 이 위키로 가장 자주 하고 싶은 질문 3가지는?
   - 논문을 비교할 때 꼭 보는 수치 지표와 단위는? 쓰는 FoM이 있으면 식도 알려 주세요.
   - 수치 비교에 영향을 주는 측정 조건은? (예: 공정, 주파수, 거리, 데이터셋)
   - 지켜보는 연구 그룹과, 내 연구의 직접 비교 대상 논문이 있나요?
3. 답을 바탕으로 만든다.
   - **주제 태그 8~15개** (영어 소문자-하이픈). 겹치는 태그는 합친다.
   - **지표 목록**(단위 포함)과 **측정 조건 목록**.
   - FoM 식이 있으면 `wiki/metrics/<이름>.md` 초안.
   - `wiki/my-research.md` 초안.
4. 초안을 보여 주고 확인받은 뒤 `AGENTS.md` 9장, `wiki/my-research.md`, `wiki/metrics/`를 쓴다. 다른 장은 건드리지 않는다.
5. `wiki/index.md`의 "주제별"에 태그별 빈 제목을, "연구 그룹"에 그룹 이름을 만든다.
6. `raw/papers/`에 PDF가 있으면 개수를 알리고 "`$wiki-ingest`로 소화할까요? 비교 대상 논문부터 하는 것을 권합니다"라고 묻는다.
7. `wiki/log.md`에 `- 날짜 | setup | AGENTS.md 9장 | 태그 N개, 지표 M개 설정` 추가.
