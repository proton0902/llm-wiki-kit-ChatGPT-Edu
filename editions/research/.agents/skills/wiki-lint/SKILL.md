# 위키 건강검진 (연구자용)

## 1. 기계적 점검
`python3 scripts/wiki_stats.py` 실행: 페이지·링크 수, 깨진 링크, 고아 페이지, 위치 표기 없는 논문 페이지, 원문 파일 없는 페이지, 미소화 raw 파일.
추가로 직접 센다: `references.bib`에 없는 `bibkey`, `version_of`가 한쪽만 걸린 쌍.

## 2. 내용 점검
- **모순**: 같은 논문·지표의 수치가 페이지마다 다른 곳 → 원문 확인.
- **조건 누락**: 비교표·개념 페이지에서 조건 없는 수치.
- **표기 누락**: "최초", "최고", "state-of-the-art"가 `[저자 주장]` 없이 쓰인 곳. sim/meas 구분 없는 수치.
- **FoM 불일치**: 같은 이름, 다른 정의로 비교된 곳.
- **중복**: 같은 개념 페이지 두 개 → 합치고 링크로.
- **버전 관계**: 같은 저자·같은 시스템인데 `version_of` 없는 논문.
- **오래된 정보**: 더 새 논문 기준으로 틀린 "최고 성능" 서술.
- **비공개 누출**: 공개 페이지(papers, concepts 등)에 `raw/notes/`나 `wiki/ideas/` 내용이 들어간 곳.

## 3. 고치기
- 먼저 표로 보여 준다: `| 종류 | 위치 | 내용 | 제안 |`.
- 사용자가 동의하면 고치고, 원문 확인이 필요한 항목은 `(확인 필요)`로 남긴다. `raw/`는 수정하지 않는다.

## 4. 기록
`wiki/log.md`에 `- 날짜 | lint | 전체 | 발견 N건, 수정 M건, 확인필요 K건` 과 1번 통계 한 줄. (위키 성장 기록이 됩니다.)
