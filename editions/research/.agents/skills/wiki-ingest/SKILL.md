# 자료 소화 (연구자용)

## 0. 대상 찾기
- 파일을 지정하지 않으면 `raw/` 아래 파일 중 어떤 페이지의 `source:`에도 없는 파일을 찾아 목록을 보여 준다.
- 5편 이상이면 나눠서 진행할지 묻는다. `relation`이 baseline·competitor일 것 같은 논문(9장의 비교 대상)을 먼저 하자고 제안한다.
- 한 번에 한 편씩 끝까지 처리한다.

## 1. 원문 읽기 (위치 보존)
- `python3 scripts/pdf_pages.py raw/papers/파일.pdf` 로 쪽 번호가 붙은 텍스트를 읽는다 (`=== p.N ===`). 실패하면 `pdftotext -layout`, 그래도 실패하면 사용자에게 알린다.
- 그림·표 안 수치는 텍스트로 깨지기 쉽다. 깨진 수치는 쓰지 말고 `(Table N, p.M, 확인 필요)`로 남긴다.
- 원문 파일은 절대 수정하지 않는다.

## 2. 논문 페이지 쓰기
- `AGENTS.md` 5장 논문 양식을 그대로 따른다. 모든 사실·수치에 위치를 단다.
- `AGENTS.md` 3장 구분 표기를 지킨다: 사실 / `[저자 주장]` / `[해석]`, `(sim.)` / `(meas.)`.
- 9장의 "꼭 기록할 수치 지표"는 원문에 있으면 반드시 "주요 수치" 표에, 없으면 "원문에 없음".
- `relation`은 `wiki/my-research.md`를 읽고 판단한다. 판단이 어려우면 `related`로 두고 이유를 쓴다.
- `reproducibility`: 원문에 코드·데이터 링크가 있을 때만 code/data로 쓴다.
- 태그는 9장 목록에서 고른다. 새 태그가 필요하면 제안만 한다.

## 3. 연결하기
- `index.md`, `wiki/concepts/`, `wiki/papers/`, `wiki/groups/`를 훑어 관련 페이지를 찾는다.
- 관련 개념 페이지의 표·타임라인에 이 논문을 추가한다(위치 포함). 개념 페이지는 **2편 이상**이 다루는 개념일 때만 새로 만든다.
- 학회판-저널판-프리프린트 관계면 `version_of:`로 양쪽을 연결하고 수치 차이를 확인한다(4장).
- 그룹 페이지에 논문을 추가하거나 새로 만든다.
- 논문이 다루지만 아무도 답하지 않은 질문이 보이면 `wiki/questions/`에 추가하거나 기존 질문에 근거를 보탠다.

## 4. 서지
- `wiki/references.bib`에 BibTeX를 추가한다(`bibkey`와 같은 키). 원문에서 확인한 필드만 쓴다. DOI·쪽수를 지어내지 않는다.

## 5. 마무리
- `wiki/index.md` 해당 주제 아래 `- [[papers/페이지명]] — 한 줄 요약` 추가.
- `wiki/log.md`에 `- 날짜 | ingest | 페이지명 | 새 페이지 N개, 수정 M개, 확인필요 K개` 추가.
- 사용자에게 보고: 한 줄 요약, 내 연구와의 관계, 새로 만든/고친 페이지, 확인 필요 항목.
