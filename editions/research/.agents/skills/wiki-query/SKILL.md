# 질문하기 (Query)

## 절차
1. **`wiki/index.md`에서 출발한다.** 질문과 관련된 페이지를 고른다. 위키 전체를 무작정 읽지 않는다.
2. 고른 페이지와 그 페이지의 "관련 페이지"를 읽는다. 보통 3~10개 페이지면 충분하다.
3. 답에 쓸 수치나 핵심 주장은 **원문 쪽 번호까지 확인한다.** 위키 요약만 믿지 말고, 수치가 답의 핵심이면 `raw/` 원문의 해당 쪽을 열어 대조한다.
4. 답변 형식:
   - 첫 문장에 결론.
   - 근거는 항목마다 `([[papers/페이지명]], p.N)` 출처.
   - 비교 질문이면 조건을 포함한 표.
   - 위키에 없는 내용이면 "위키와 원문에서 근거를 찾지 못했습니다"라고 쓰고, 어떤 논문을 더 넣으면 답할 수 있을지 제안한다. 일반 지식으로 메우지 않는다. 사용자가 일반 지식도 원하면 그 부분을 `(위키 밖 일반 지식)`으로 구분한다.
   - 마지막 줄에 "읽은 페이지: …" 목록.
5. 답이 다시 쓸 만하면(비교표, 동향 정리 등) `wiki/answers/YYYY-MM-DD-주제.md`로 저장할지 묻는다. 저장하면 관련 개념 페이지에서 링크한다.
6. 답하다가 위키의 오류·누락을 발견하면 답변 끝에 알리고, 사용자가 동의하면 고친다.
7. `wiki/log.md`에 `- 날짜 | query | 질문 요약 | 읽은 페이지 N개` 를 추가한다.
