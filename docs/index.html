1단계

어떤 판이 맞을까요?

둘 다 같은 원리이고, 넣는 자료와 만들어지는 페이지가 다릅니다. 고르면 아래 설치 명령이 바뀝니다.

학부생 · 수강생 · 독학자

학습용 (Study-Wiki)

  • 넣는 것: 강의 슬라이드, 교재, 필기, 기출
  • 만드는 것: 과목 허브, 주차별 강의 노트, 개념 카드, 문제 풀이
  • 전용 명령: $wiki-quiz 퀴즈·복습 일정, $wiki-exam 시험 대비 요약
  • 채점 과제는 답 대신 힌트만 줍니다
대학원생 · 연구원 · 교수

연구자용 (LLM-Wiki)

  • 넣는 것: 논문 PDF, 데이터시트, 미팅 노트
  • 만드는 것: 논문 페이지, 개념, 지표(FoM), 연구 그룹, 열린 질문
  • 전용 명령: $wiki-compare 선행연구 비교표, $wiki-novelty 아이디어 중복 확인
  • 사실 / 저자 주장 / 해석을 구분해 씁니다
2단계

설치: 명령 한 줄 복사해서 붙여넣기

설치는 GitHub에서 템플릿 폴더를 받아 새 폴더에 복사하는 것이 전부입니다. 기존 폴더는 덮어쓰지 않습니다.

설치가 끝나면 Study-Wiki 폴더가 생깁니다. 이 폴더 하나가 위키 전체이고, 지워도 다른 곳에는 영향이 없습니다.
3단계

3분 시작하기

설치한 다음 이 순서대로 하면 첫 답변까지 갑니다.

  1. 자료 넣기

    강의 슬라이드는 raw/lectures/과목이름/, 교재는 raw/textbooks/, 필기는 raw/notes/에 넣습니다. 파일 탐색기에서 끌어다 놓으면 됩니다.

  2. Codex로 위키 폴더 열기

    ChatGPT 데스크톱 앱의 Codex, VS Code 확장, 또는 터미널에서 위키 폴더로 이동해 codex. 학교 계정(ChatGPT Edu)으로 로그인합니다.

  3. $wiki-setup 입력

    이번 학기 과목을 묻고 과목 허브 페이지를 만들어 줍니다. 강의계획서가 있으면 같이 읽습니다.

  4. $wiki-ingest 입력

    넣은 자료를 하나씩 읽고 페이지를 만들어 서로 연결합니다. 자료가 많으면 "1~3주차만 먼저"처럼 나눠서 시키세요.

  5. 그냥 질문하기

    "3주차 테브난 등가회로 쉽게 설명해줘", "중간고사 범위로 퀴즈 5개 내줘"

  6. (선택) 위키 보기

    브라우저에서 바로 보려면 위키 뷰어에서 위키 폴더를 여세요. 위키 폴더를 Obsidian 보관소로 열면 페이지 사이 연결을 그래프로 볼 수 있습니다. 폴더 안의 Obsidian 사용법.md를 참고하세요.

막히면 여기부터

웹사이트에서 내 위키를 볼 수 있나요?

위키를 읽고 정리하는 일은 내 학교 계정으로 로그인한 Codex가 PC 폴더에서 합니다. 대신 위키 뷰어에서 "위키 폴더 열기"를 누르면 목차, 페이지, 링크, 검색, 오늘 복습할 개념을 브라우저에서 바로 볼 수 있습니다. 파일은 내 브라우저 안에서만 읽고 어디에도 올라가지 않습니다. 위키가 아직 없다면 "학습용 예시 위키 보기"나 "연구자용 예시 위키 보기"를 눌러 보세요.

Codex는 어디서 여나요?

ChatGPT 데스크톱 앱의 Codex, VS Code의 Codex 확장, 또는 터미널의 codex 중 편한 것을 쓰세요. 중요한 건 위키 폴더를 작업 폴더로 열기입니다. 그래야 AGENTS.md 규칙과 $wiki-… 명령을 읽습니다.

$wiki-setup을 쳐도 명령이 안 보여요.
  • Codex를 위키 폴더(예: Study-Wiki)에서 열었는지 확인하세요. 상위 폴더에서 열면 명령을 못 찾습니다.
  • Codex를 껐다 다시 열거나 /skills로 목록을 확인하세요.
  • 명령 없이 "위키 설정해줘"라고 말해도 같은 일을 합니다.
Windows에서 설치 중 Python 관련 오류가 나요.

Python은 선택 사항입니다. 최신 설치 스크립트는 Microsoft Store의 Python 바로가기 때문에 멈추지 않도록 고쳐져 있으니 명령을 다시 실행하세요. 그래도 안 되면 "터미널 없이" 탭의 ZIP 방법을 쓰세요.

"폴더가 이미 있고 비어 있지 않습니다"라고 나와요.

기존 위키를 덮어쓰지 않으려고 멈춘 것입니다. 다른 위치에 만들려면 macOS는 명령 끝에 경로를 붙이고(… --study ~/Documents/회로이론), Windows는 먼저 $env:LLM_WIKI_DIR = "D:\회로이론"을 실행한 뒤 설치 명령을 실행하세요.

Obsidian은 꼭 깔아야 하나요?

아니요. 위키는 평범한 마크다운(.md) 파일이라 어떤 편집기로도 열립니다. Obsidian은 페이지 연결을 그래프로 보고 링크를 클릭해 오가기 편해서 권장할 뿐입니다.

과제 답을 대신 써 주나요?

학습용은 채점되는 과제의 완성 답안을 쓰지 않습니다. 개념 설명, 비슷한 예제, 단계별 힌트, 내가 쓴 풀이에 대한 피드백을 줍니다. 제출이 끝났거나 연습문제·기출이라고 밝히면 전체 풀이를 보여 줍니다.

내 자료는 어디로 가나요?
  • 원본과 위키 파일은 내 PC 폴더에만 있습니다. 설치 스크립트는 아무 정보도 외부로 보내지 않습니다.
  • Codex가 읽은 내용은 답변 생성을 위해 OpenAI로 전송되므로 학교 ChatGPT Edu 계정으로 쓰고, 학교 방침상 올리면 안 되는 자료는 넣지 마세요.
  • 위키를 공유할 때 .gitignore가 raw/ 원본과 개인 메모를 기본으로 빼 줍니다.
답이 정확한지 어떻게 믿나요?

모든 문장에 슬라이드·쪽 번호 출처를 달도록 규칙이 정해져 있으니 중요한 내용은 원문을 바로 확인할 수 있습니다. 직접 재 보고 싶다면 eval/ 폴더의 방법대로 일반 채팅과 위키의 정답률을 비교해 보세요.

설치 스크립트가 무슨 일을 하는지 먼저 보고 싶어요.

install.sh, install.ps1을 읽어 보거나 ZIP으로 받으세요. 관리자 권한을 쓰지 않고, 템플릿을 받아 새 폴더에 복사하며, Obsidian 설치는 물어본 뒤에만 합니다.
