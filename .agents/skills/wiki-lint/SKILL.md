# 위키 건강검진 (Lint)

## 1. 기계적 점검 (스크립트로 센다)
`python3 scripts/wiki_stats.py` 를 실행해 다음을 얻는다:
페이지 수, 내부 링크 수, 깨진 링크, 들어오는 링크가 없는 고아 페이지, 출처 표기가 없는 논문 페이지, `source:` 파일이 없는 페이지, 아직 소화 안 된 raw 파일.

## 2. 내용 점검 (읽고 판단)
- **모순**: 같은 논문·같은 지표에 대해 페이지마다 수치가 다른 곳. 원문을 열어 맞는 값을 확인한다.
- **조건 누락**: 비교표에 조건 없이 수치만 있는 행.
- **중복**: 같은 개념을 다룬 페이지 두 개 → 하나로 합치고 다른 쪽은 링크로 바꾼다.
- **학회판-저널판 관계**: 같은 저자·같은 시스템인데 서로 연결 안 된 논문.
- **오래된 정보**: "최고 성능", "최초" 같은 표현이 더 새 논문 기준으로 틀린 곳.

## 3. 고치기
- 고치기 전에 발견 목록을 표로 보여 준다: `| 종류 | 위치 | 내용 | 제안 |`.
- 사용자가 "다 고쳐"라고 하면 고치고, 원문 확인이 필요한 항목은 `(확인 필요)`로 남긴다.
- `raw/`는 절대 수정하지 않는다.

## 4. 기록
`wiki/log.md`에 `- 날짜 | lint | 전체 | 발견 N건, 수정 M건, 확인필요 K건` 을 추가하고, 1번의 통계도 한 줄로 남긴다. (이 통계가 쌓이면 위키 성장 기록이 된다.)
