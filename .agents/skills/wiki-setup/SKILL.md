# 위키 맞춤 설정

목표: 5분 안에 이 위키를 사용자의 연구 분야에 맞춘다.

## 절차
1. `AGENTS.md`를 읽는다. 6장이 이미 채워져 있으면 현재 값을 보여 주고 무엇을 바꿀지 묻는다.
2. 사용자에게 아래 질문을 **한 번에** 묻는다. 모르면 비워도 된다고 안내한다.
   - 연구 분야를 한두 문장으로 설명해 주세요.
   - 이 위키로 가장 자주 하고 싶은 질문 3가지는?
   - 논문을 비교할 때 꼭 보는 수치 지표는? (예: 효율, 전력, 데이터레이트, 정확도, 표본 수)
   - 지켜보는 연구 그룹(기관·교수·회사)이 있나요?
3. 답을 바탕으로 다음을 만든다.
   - **주제 태그 8~15개**: 영어 소문자-하이픈 형식 (예: `body-channel`, `energy-harvesting`). 너무 넓거나 겹치는 태그는 합친다.
   - **꼭 기록할 수치 지표**: 단위 포함 (예: `효율 (%)`, `전력 (µW)`).
4. 만든 초안을 보여 주고 확인받은 뒤 `AGENTS.md` 6장을 고친다. 다른 장은 건드리지 않는다.
5. `wiki/index.md`의 "주제별" 목록에 태그별 빈 제목을 만든다.
6. `raw/papers/`에 이미 PDF가 있으면 개수를 알려 주고 "`$wiki-ingest`로 전부 소화할까요?"라고 묻는다.
7. `wiki/log.md`에 `- 날짜 | setup | AGENTS.md 6장 | 태그 N개 설정`을 추가한다.
