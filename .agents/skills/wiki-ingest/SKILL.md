# 자료 소화 (Ingest)

## 0. 대상 찾기
- 사용자가 파일을 지정하지 않으면 `raw/` 아래 파일 중 어떤 논문 페이지의 `source:`에도 없는 파일을 찾아 목록을 보여 준다.
- 5편 이상이면 몇 편씩 나눠 진행할지 묻는다. 한 번에 한 편씩 끝까지 처리한다(여러 편을 동시에 반쯤 하지 않는다).

## 1. 원문 읽기 (쪽 번호 보존)
- PDF는 쪽 번호가 붙은 텍스트로 바꿔 읽는다:
  `python3 .agents/skills/wiki-ingest/scripts/pdf_pages.py raw/papers/파일.pdf`
  (출력의 `=== p.N ===` 표시가 쪽 번호다. 스크립트가 실패하면 `pdftotext -layout`을 쓰고, 그래도 실패하면 사용자에게 알린다.)
- 그림·표 안의 수치는 텍스트로 깨질 수 있다. 깨진 수치는 쓰지 말고 `(표 N, 확인 필요)`로 남긴다.
- 원문 파일은 절대 수정하지 않는다.

## 2. 논문 페이지 쓰기
- `AGENTS.md` 3장의 논문 페이지 양식을 그대로 따른다.
- 파일명: `wiki/papers/<첫저자성 소문자>-<연도>-<핵심어>.md`.
- 모든 사실 문장과 수치에 쪽 번호를 단다.
- `AGENTS.md` 6장의 "꼭 기록할 수치 지표"는 원문에 있으면 반드시 "주요 수치" 표에 넣는다. 없으면 "원문에 없음"으로 쓴다.
- 태그는 6장의 태그 목록에서 고른다. 맞는 태그가 없으면 새로 만들지 말고 사용자에게 제안만 한다.

## 3. 연결하기
- `index.md`와 `wiki/concepts/`, `wiki/papers/`를 훑어 관련 페이지를 찾는다.
- 관련 개념 페이지가 있으면 그 페이지의 표와 동향 목록에 이 논문을 추가한다(쪽 번호 포함).
- 없으면, 이 논문 포함 **2편 이상**이 다루는 개념일 때만 새 개념 페이지를 만든다.
- 같은 저자의 학회판-저널판, 후속 연구, 경쟁 방식은 서로 "관련 페이지"에 관계와 함께 적는다.
- 연구 그룹 페이지가 있으면 논문 목록에 추가하고, 없으면 새로 만든다.

## 4. 마무리
- `wiki/index.md`의 해당 주제 아래에 `- [[papers/페이지명]] — 한 줄 요약` 을 추가한다.
- `wiki/log.md`에 `- 날짜 | ingest | 페이지명 | 새 페이지 N개, 수정 M개` 를 추가한다.
- 사용자에게 보고: 한 줄 요약, 새로 만든/고친 페이지 목록, 확인 필요로 남긴 항목.
