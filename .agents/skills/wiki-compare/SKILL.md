# 선행연구 비교표 만들기

## 절차
1. 비교 범위를 확인한다: 어떤 논문들(태그, 그룹, 연도, 직접 지정), 어떤 지표(기본값은 `AGENTS.md` 6장의 "꼭 기록할 수치 지표"), 사용자의 연구를 마지막 열에 넣을지.
2. 각 논문 페이지의 "주요 수치" 표에서 값을 모은다. **비어 있거나 `확인 필요`인 칸은 원문을 열어 채운다.** 원문에도 없으면 `–`로 두고 각주에 "원문에 없음".
3. 표를 만든다.
   - 행 = 지표, 열 = 논문 (학계 관례). 열 머리에는 `저자 Venue'YY`와 링크.
   - 단위는 행 이름에 쓴다. 단위가 다른 값은 환산하고 각주에 원래 값을 남긴다.
   - 모든 칸에 쪽 번호를 각주나 괄호로 단다.
   - 측정 조건이 다르면 같은 행에 억지로 넣지 말고 조건 행을 따로 둔다.
4. 표 아래에 "이 표로 말할 수 있는 것 / 말할 수 없는 것"을 2~4줄로 쓴다. 조건이 달라 직접 비교가 어려운 칸을 명시한다.
5. 결과를 `wiki/answers/YYYY-MM-DD-비교표-주제.md`에 저장하고, 원하면 LaTeX `tabular`나 CSV도 함께 만든다.
6. `wiki/log.md`에 `- 날짜 | compare | 주제 | 논문 N편 × 지표 M개, 원문 대조 K칸` 을 추가한다.
